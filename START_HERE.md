## 💡 Tips

### For Best AR Experience:
1. Use **clear, detailed** marker images
2. Good **lighting** when scanning
3. Keep marker **flat**
4. Hold phone **steady** (30-50cm away)
5. Test on **mobile device** (real camera)

### For Development:
1. Always test build before pushing
2. Use meaningful commit messages
3. Update docs if changing features
4. Test on multiple browsers/devices
